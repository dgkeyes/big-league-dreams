# big-league-dreams
A baseball game made by Elias Keyes (and Claude)

## Run it

```sh
pnpm install
pnpm dev      # http://localhost:5173, also reachable from an iPad on the same Wi-Fi
pnpm build    # static site in dist/
```

Play on an iPad in Safari, held sideways. Use Share, then Add to Home Screen, to play it full screen like an app.

## The first prototype

- **Make your player:** boy or girl, and one of four Portland leagues.
- **T-ball game:** tap when the arrow is in the green to smack the ball off the tee.
- **Home run quest:** hit 5 homers off Rocket Rosie in 15 pitches. Tap when the ball reaches home plate. Winning earns 10 tokens.

Progress (tokens, quest done) is saved in the browser.
